Roadmap

Where the project is, and the gaps it intends to work on. Direction, not dated commitments.

The canonical, up-to-date roadmap is ROADMAP.md in the repository. This page summarizes it.

Available now

  • Backstage pluginsCore engine, common types, catalog and permission adapters, backend plugin and frontend plugin on Backstage 1.55.
  • npm packagesAll five packages published under @contextverity with provenance.
  • Kubernetes labA Podman-built image and Helm chart (non-root, read-only root filesystem, NetworkPolicy), validated on kind with a scenario tier.
  • Receipts and verificationImmutable, integrity-tagged receipts; typed drift codes; VALID, REFRESH and DENY.
  • Agent tool pathTwo actions exposed as MCP tools through the official MCP Actions backend.
  • ObservabilityOpenTelemetry spans and metrics for resolution and verification.
  • Reproducible evaluationScenario suites for an in-process tier and a live local Backstage lab, published on the results page.

Gaps we intend to work on

  • TechDocs content provenanceToday only the TechDocs reference annotation is tracked.
  • Per-agent identity over MCPPreserve distinct agent identities where Backstage makes that possible, instead of a shared static-token identity.
  • Production-mode benchmarksLatency on PostgreSQL and a built backend, published separately from today's development-lab numbers.
  • Precondition-based verify-and-actFor actions that support optimistic concurrency, to narrow the check-to-use window.
  • LaterMore source providers (for example Git or Kubernetes), optional authorization providers such as OpenFGA where they solve a real problem, and portable signed receipts on a mature standard.
  • Not plannedAn MCP server, AI gateway or prompt-injection detector, or any language-model-based decision in the verifier.
  • Real-world feedbackEvaluation beyond synthetic, single-machine scenarios, with platform teams willing to try it.

ContextVerity

ContextVerity is an independent Apache-2.0 open-source project built using open technologies from the Backstage, Kubernetes, CNCF and Linux Foundation ecosystems. It is not a CNCF project and not an official Backstage project.

Backstage, OpenTelemetry and Model Context Protocol are projects of their respective foundations and are named here only to describe integrations. This site uses no cookies, analytics or third-party resources.
