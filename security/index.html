Security

What ContextVerity checks, what it trusts, and how to report a vulnerability.

Report a vulnerability

Use GitHub Private Vulnerability Reporting: open a private security advisory. Please do not open public issues for security problems. See SECURITY.md for scope and supported versions.

Security model in brief

What verification checks

  • Receipt integrityStored receipts carry an HMAC-SHA256 integrity tag. A tampered record yields RECEIPT_INTEGRITY_FAILED and DENY.
  • BindingConsumer, issuer, subject, purpose and scope must match the receipt.
  • Authorizationcatalog.entity.read is re-evaluated for the consumer through the Backstage Permission Framework.
  • PolicyA removed or narrowed grant yields DENY; a classification above the grant ceiling yields DENY.
  • Source stateSources are re-fetched and compared by digest and field; deletions, recreations and outages are reported.
  • DeterminismNo language model is involved in any decision, so verdicts are reproducible and explainable.

What it trusts or does not cover

  • Source truthThe Backstage catalog is trusted. Wrong or compromised catalog data is recorded faithfully.
  • Point-in-time resultsChanges after verification (TOCTOU) are not covered.
  • Advisory integrationOther plugins' actions are not intercepted. Agents must call verify and honour the verdict.
  • Identity limitsService principals are not subject to Backstage permission policies, and static-token MCP agents share the plugin:mcp-actions identity.
  • Agent contentContextVerity does not inspect prompts or model output. It is not a prompt-injection or hallucination detector, and not an AI firewall.

ContextVerity

ContextVerity is an independent Apache-2.0 open-source project built using open technologies from the Backstage, Kubernetes, CNCF and Linux Foundation ecosystems. It is not a CNCF project and not an official Backstage project.

Backstage, OpenTelemetry and Model Context Protocol are projects of their respective foundations and are named here only to describe integrations. This site uses no cookies, analytics or third-party resources.
