Demo

Run ContextVerity on a local Backstage in a few minutes, or step through recorded test scenarios right here in the browser.

Run it yourself

git clone https://github.com/contextverity/contextverity && cd contextverity && make install && make demo-up && make demo-run

When you are done:

make demo-down

make demo-mcp runs the same flow through the official Backstage MCP Actions endpoint.

Prerequisites

  • Node.js 22 or 24
  • No cloud credentials
  • No LLM key

make demo-up starts a local Backstage lab (backend and frontend) with synthetic catalog data. make demo-run makes real calls against it: it resolves context, changes the catalog and permissions, and verifies the receipts.

The lab serves the Backstage app at http://127.0.0.1:3000 and the backend at http://127.0.0.1:7007.
