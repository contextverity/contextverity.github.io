Contributing

ContextVerity is Apache-2.0 and developed in the open. Issues, reviews, docs and code are all welcome.

Get set up

git clone https://github.com/contextverity/contextverity
cd contextverity
make install
make verify

Requires Node.js 22 or 24. make verify runs formatting, lint, type checks and tests, the same checks CI runs. make test-results regenerates the machine-readable results shown on this site.

Ways to help

  • Try the demo and report what was unclear.
  • Review the threat model and limitations; challenge anything that looks overstated.
  • Propose a scenario that should produce a different verdict.
  • Improve docs, examples and the Backstage integration.

Read CONTRIBUTING.md before opening a pull request. Report security issues privately, as described on the security page.

This website

The site lives in contextverity/contextverity.github.io: plain HTML, CSS and JavaScript with no build step. Result data is copied from a ContextVerity checkout with node scripts/sync-results.mjs, and node scripts/check-site.mjs validates links, assets and data before deployment.

ContextVerity

ContextVerity is an independent Apache-2.0 open-source project built using open technologies from the Backstage, Kubernetes, CNCF and Linux Foundation ecosystems. It is not a CNCF project and not an official Backstage project.

Backstage, OpenTelemetry and Model Context Protocol are projects of their respective foundations and are named here only to describe integrations. This site uses no cookies, analytics or third-party resources.
